## 3.3.2 推理过程详解：以 "Your journey starts with one step" 为例

### 核心思路
3.3.1 节只为第 2 个 token（journey）单独计算了 attention，3.3.2 将其推广到**一次性并行计算所有 6 个 token 的 context vector**。本质上就是把之前的 for 循环全部换成**矩阵乘法**。

---

### 输入：6 个 token 的 3 维词嵌入

```python
inputs = tensor([
  [0.43, 0.15, 0.89],   # x¹: Your
  [0.55, 0.87, 0.66],   # x²: journey
  [0.57, 0.85, 0.64],   # x³: starts
  [0.22, 0.58, 0.33],   # x⁴: with
  [0.77, 0.25, 0.10],   # x⁵: one
  [0.05, 0.80, 0.55]])  # x⁶: step
```

shape = `(6, 3)`，每行一个 token，每列一个 embedding 维度。

---

### Step 1：计算注意力分数矩阵（点积相似度）

**公式**：`attn_scores = inputs @ inputs.T`

这步等价于对每对 token `(i, j)` 计算点积 `ωᵢⱼ = xⁱ · xʲ`。6×6 矩阵中，**第 i 行表示"以 xⁱ 为 query 对所有 token 的打分"**。

#### 以 journey (x²) 为例手动算几个：

| 分数 | 计算 | 结果 | 含义 |
|---|---|---|---|
| ω₂₂ = x²·x² | 0.55×0.55 + 0.87×0.87 + 0.66×0.66 | **1.4950** | journey 跟自己最像 |
| ω₂₃ = x²·x³ | 0.55×0.57 + 0.87×0.85 + 0.66×0.64 | **1.4754** | journey 和 starts 几乎一样像 |
| ω₂₆ = x²·x⁶ | 0.55×0.05 + 0.87×0.80 + 0.66×0.55 | **1.0865** | journey 跟 step 也比较像 |
| ω₂₁ = x²·x¹ | 0.55×0.43 + 0.87×0.15 + 0.66×0.89 | **0.9544** | journey 跟 Your 中等相似 |
| ω₂₅ = x²·x⁵ | 0.55×0.77 + 0.87×0.25 + 0.66×0.10 | **0.7070** | journey 跟 one 最不像 |

完整的 6×6 分数矩阵：
```
[[0.9995, 0.9544, 0.9422, 0.4753, 0.4576, 0.6310],   ← x¹(Your) 作为 query
 [0.9544, 1.4950, 1.4754, 0.8434, 0.7070, 1.0865],   ← x²(journey) 作为 query
 [0.9422, 1.4754, 1.4570, 0.8296, 0.7154, 1.0605],   ← x³(starts)
 [0.4753, 0.8434, 0.8296, 0.4937, 0.3474, 0.6565],   ← x⁴(with)
 [0.4576, 0.7070, 0.7154, 0.3474, 0.6654, 0.2935],   ← x⁵(one)
 [0.6310, 1.0865, 1.0605, 0.6565, 0.2935, 0.9450]]   ← x⁶(step)
```
矩阵关于对角线**对称**（点积交换律），对角线是每个 token 跟自己的相似度。

---

### Step 2：softmax 归一化（每行独立）

**代码**：`attn_weights = torch.softmax(attn_scores, dim=-1)`

`dim=-1` 表示对**每一行**独立做 softmax，让每行 6 个数变成概率分布（和为 1）。

#### journey 行（第 2 行）的完整 softmax 推导：

```
原始分数:  [0.9544, 1.4950, 1.4754, 0.8434, 0.7070, 1.0865]
        exp:   2.5971, 4.4593, 4.3728, 2.3243, 2.0279, 2.9639   ← 单调递增，保序
        求和:  18.7453
归一化:   [0.1385, 0.2379, 0.2333, 0.1240, 0.1082, 0.1581]   ← 4.4593/18.7453=0.2379
```

softmax 做了两件事：
1. **保序放大**：原本的分数相对大小不变，但差距被拉大了（最大 1.495 变成 0.2379，最小 0.707 变成 0.1082，比例从 2.1× 变成 2.2×）
2. **归一化到概率分布**：6 个权重加起来正好 = 1.0

归一化后的完整权重矩阵：
```
[[0.2098, 0.2006, 0.1981, 0.1242, 0.1220, 0.1452],   ← Your 的关注分布（最均匀）
 [0.1385, 0.2379, 0.2333, 0.1240, 0.1082, 0.1581],   ← journey 的关注分布
 [0.1390, 0.2369, 0.2326, 0.1242, 0.1108, 0.1565],   ← starts 的关注分布
 [0.1435, 0.2074, 0.2046, 0.1462, 0.1263, 0.1720],   ← with 的关注分布
 [0.1526, 0.1958, 0.1975, 0.1367, 0.1879, 0.1295],   ← one 的关注分布
 [0.1385, 0.2184, 0.2128, 0.1420, 0.0988, 0.1896]]   ← step 的关注分布
```

#### 关键洞察：journey 最关注谁？

| 排名 | Token | 权重 | 解读 |
|---|---|---|---|
| #1 | **journey** (自身) | 0.2379 | 自己跟自己最像 |
| #2 | **starts** | 0.2333 | 词向量几乎一样（都有 0.85/0.87 第二维高峰） |
| #3 | **step** | 0.1581 | 也是"动作性"的词 |
| #4 | Your | 0.1385 | |
| #5 | with | 0.1240 | |
| #6 | **one** | 0.1082 | 唯一高在第一维（0.77）的词，最不像 |

这说明：embedding 空间中"靠近"的 token 在 attention 中会互相亮绿灯。这是一个**无训练权重**的简单 self-attention（纯靠初始 embedding 的几何关系），第 3.4 节引入可训练的 W_q/W_k/W_v 之后才能学到真正有语义的关注。

### Step 3：加权求和得到上下文向量

**代码**：`all_context_vecs = attn_weights @ inputs`

矩阵乘法：`(6×6) @ (6×3) = (6×3)`。第 i 行 = `Σⱼ wᵢⱼ · xʲ`。

#### 手动展开 journey 的上下文向量 z²：

```
z² = 0.1385·x¹ + 0.2379·x² + 0.2333·x³ + 0.1240·x⁴ + 0.1082·x⁵ + 0.1581·x⁶

z²[0] = 0.1385×0.43 + 0.2379×0.55 + 0.2333×0.57 + 0.1240×0.22 + 0.1082×0.77 + 0.1581×0.05
      = 0.4419

z²[1] = 0.1385×0.15 + 0.2379×0.87 + 0.2333×0.85 + 0.1240×0.58 + 0.1082×0.25 + 0.1581×0.80
      = 0.6515

z²[2] = 0.1385×0.89 + 0.2379×0.66 + 0.2333×0.64 + 0.1240×0.33 + 0.1082×0.10 + 0.1581×0.55
      = 0.5683
```

对比原来的 x² = `[0.55, 0.87, 0.66]`，z² = `[0.4419, 0.6515, 0.5683]`：
- 每个维度都被**拉向了全句的加权平均**
- 但因为 journey 主要关注自身和 starts（权重合计 0.47），所以 z² 依然保留了 journey/starts 那组高在第 2 维（0.65）、中高在第 3 维（0.57）的特征
- L2 距离从 journey 到它的上下文向量 = 0.2605，不算太大（因为 journey 跟 starts 本身就很像）

所有 6 个 token 的变换对比：

| Token | 原始 xⁱ | 上下文 zⁱ | L2 距离 | 解读 |
|---|---|---|---|---|
| Your | [0.43, 0.15, 0.89] | [0.44, 0.59, 0.58] | 0.54 | 被其他 token "往第 2 维拉"了很多 |
| journey | [0.55, 0.87, 0.66] | [0.44, 0.65, 0.57] | 0.26 | 保留了自相似，变化较小 |
| starts | [0.57, 0.85, 0.64] | [0.44, 0.65, 0.57] | 0.25 | 跟 journey 几乎一样 → 几乎一样的上下文向量 |
| with | [0.22, 0.58, 0.33] | [0.43, 0.63, 0.55] | 0.31 | 原本三维都低，被整体拉高 |
| one | [0.77, 0.25, 0.10] | [0.47, 0.59, 0.53] | **0.62** | 原始 token 最"孤僻"，被上下文影响最大 |
| step | [0.05, 0.80, 0.55] | [0.42, 0.65, 0.56] | 0.40 | 第一维从 0.05 被显著拉到 0.42 |

### 3.3.2 vs 3.3.1 的关系

3.3.1 只算 journey 一个：

```python
# 3.3.1: 先算分数 → softmax → 加权求和
query = inputs[1]
attn_scores_2 = torch.tensor([torch.dot(x_i, query) for x_i in inputs])
attn_weights_2 = torch.softmax(attn_scores_2, dim=0)
context_vec_2 = torch.zeros(query.shape)
for i, x_i in enumerate(inputs):
    context_vec_2 += attn_weights_2[i] * x_i
```

3.3.2 一次性算全部：

```python
# 3.3.2: 矩阵乘法一步到位
attn_scores = inputs @ inputs.T          # 一次算完所有 6×6 个点积
attn_weights = torch.softmax(attn_scores, dim=-1)  # 对每行各自 softmax
all_context_vecs = attn_weights @ inputs  # 一次算完所有 6 个 context vector
```

**结果完全一致**：3.3.1 得到的 `context_vec_2 = [0.4419, 0.6515, 0.5683]`，就是 3.3.2 矩阵结果的第 2 行。

---

### 与后续章节的衔接

3.3.2 这是**不带可训练权重**的简单 self-attention，只用原始 embedding 做相似度。

- **3.4.1 节**引入 `W_q, W_k, W_v` 三个可训练权重矩阵：先对 `inputs` 做线性投影得到 `queries, keys, values`，再算 `attn_scores = queries @ keys.T`，并加上除以 √dₖ 的 **scaling**
- **3.4.2 节**封装成 `SelfAttention_v1 / SelfAttention_v2` 类
- **3.5 节**加入 causal mask（下三角矩阵）让每个 token 只能看见自己和前面的 token

3.3.2 是理解整条流水线的最佳切入点：矩阵形状从 `(seq_len, d)` → `(seq_len, seq_len)` → `(seq_len, d)` 的信息流向是所有 Transformer block 的骨架。
